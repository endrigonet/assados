# Fotos do cardápio

Para um item do cardápio exibir foto ao passar o mouse no título, salve a imagem
aqui usando o nome do item em minúsculas, sem acento, com hífen no lugar de espaço.

Formatos aceitos (nessa ordem de preferência): `.webp`, `.jpg`, `.jpeg`, `.png`.

Exemplos:
- "Kit Frango Assado" → `kit-frango-assado.jpg`
- "Costela Bovina" → `costela-bovina.jpg`
- "Coca-Cola 2L" → `coca-cola-2l.jpg`
- "Frango Assado Com Recheio" → `frango-assado-com-recheio.jpg`
- "Risoto + Carne Assada" → `risoto-carne-assada.jpg` (o "+" também vira hífen)

Itens sem imagem correspondente não exibem o ícone e continuam normais.
