# Fotos do carrossel

O GitHub Pages não permite "listar" o conteúdo de uma pasta automaticamente
(é apenas hospedagem de arquivos estáticos), então as fotos do carrossel são
controladas por uma lista simples em `fotos.js`.

Para adicionar, remover ou reordenar fotos:
1. Salve o arquivo de imagem nesta pasta (`assets/carrossel/`).
2. Edite `fotos.js` e inclua (ou remova) o nome do arquivo no array `window.fotosCarrossel`,
   na ordem em que devem aparecer no carrossel.

Não é necessário mexer no `index_novo.html` para trocar as fotos.
